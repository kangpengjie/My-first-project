# 移动端退次卡页面

## 项目概述

这是一个基于原桌面端退次卡页面设计的移动端适配版本，采用响应式设计和现代化的移动端交互模式。

## 功能特性

### 1. 移动端适配
- 响应式布局，适配各种手机屏幕尺寸
- 触摸友好的交互设计
- 移动端优化的字体大小和间距
- 支持深色模式

### 2. 用户界面
- **顶部导航**：返回按钮、页面标题、关闭按钮
- **表单区域**：次卡信息输入（卡名、卡号、日期、备注）
- **项目选择**：卡片式布局显示可退款项目
- **底部操作**：取消和下一步按钮

### 3. 交互功能
- **项目选择**：通过复选框选择要退款的项目
- **动态表单**：根据选择启用/禁用相关输入框
- **实时验证**：输入数值范围验证和提示
- **智能计算**：根据退回次数自动计算金额
- **状态反馈**：提交按钮状态根据表单有效性动态更新

### 4. 用户体验优化
- **加载状态**：提交时显示加载动画
- **消息提示**：Toast消息提示用户操作结果
- **确认对话框**：重要操作前的确认提示
- **表单重置**：支持表单数据重置
- **防抖处理**：优化频繁输入的性能

## 技术实现

### HTML结构
- 语义化标签结构

## 使用方法

1. 直接打开 `mobile-refund-card.html` 文件在浏览器中查看
2. 使用浏览器开发者工具切换到移动设备模拟器
3. 测试不同屏幕尺寸和交互功能

## 设计亮点

### 1. 卡片式设计
- 将原表格形式的项目信息改为卡片式布局
- 更适合移动端的触摸操作
- 清晰的视觉层次和信息分组

### 2. 渐进式表单
- 根据用户选择动态显示相关输入项
- 减少认知负担和操作复杂度
- 智能的表单验证和提示

### 3. 现代化交互
- 符合移动端设计规范的按钮和输入框
- 流畅的动画过渡效果
- 直观的状态反馈

### 4. 无障碍设计
- 合理的颜色对比度
- 键盘导航支持
- 屏幕阅读器友好
